What the preview cannot show

  • Photos come from Wikimedia Commons and other image hosts, which the preview cannot reach. Cards show their letter placeholders instead.
  • Picks, unlocks and ticks work, but reset when the preview reloads.
  • The Stripe checkout, the old order form, "Save as PDF" and Google Maps links do not run inside the preview.
  • The /jk page normally fetches the food list live from vegardwillassen.github.io. Here it uses the local copy of the sommer-26 repository as of its last commit (1 Aug 2026).
  • netlify.toml publishes only dist/, and the build does not copy jk/ into it, so /jk is only live where the repository root is served. Worth checking on the real domain.
  • npm run check currently fails on the six placeholder Stripe links (task H4), and Netlify runs it as part of the build, so a Netlify deploy of this commit stops there.
